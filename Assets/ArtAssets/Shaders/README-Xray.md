# 复古结构线模式

## 白色外轮廓描边

Xray 组件新增 **Silhouette Outline / 外轮廓描边**，默认开启，白色、2 像素。可直接调节 **启用描边、描边颜色、描边粗细（像素）、描边不透明度**，这些设置不会重新生成线框网格。

描边用组件所在物体下的原始静态 Mesh（包括子物体）合成一个整体剪影，再只画剪影外的一圈和真实开口边界。内部重叠零件不会各自增加一圈白线，模型内部也不会填白，原有透视线框仍正常显示。即便稀疏线框省略了某些细节，描边仍遵循原模型的外形。它跟随相机视角变化，Scene 和 Game 相机均可见，不会改动相机背景或场景资产。

描边自动通过 URP Render Graph 加入相机渲染，无需手动配置 Renderer Feature。每个开启描边的 Xray 组件、每个相机增加一张临时 R8 剪影纹理和两个渲染阶段（原模型掩码、全屏描边叠加）；开关关闭后不执行。资源随帧由 Render Graph 管理，最后一个组件关闭后释放临时材质。此描边沿用透视效果，场景中的遮挡物不会裁掉白边；不支持 SkinnedMeshRenderer 或材质透明裁切形状。本项目的静态机械模型已做实际渲染验证。

## 稀疏透视模式（机械装置推荐）

选中模型，在 Xray Inspector 顶部点击 **应用稀疏透视预设（推荐）**。它保持无表面填充、前后线条全部透视，在原 shader 的边线遮罩上减少显示线条，不修改导入模型。

- **Edge Mode / Sparse Structure**：把曲面法线归并为较少的方向分区，只保留分区交界和开口边界，不再描绘每个曲面分段。UV 接缝附近的微小坐标误差也会合并处理。
- **曲面分区数 / curveSegments**：曲面方向分区数，默认 **4**；越大，曲面结构线越多。
- **小零件过滤比例 / smallPartFraction**：过滤独立小零件的尺寸门槛，默认 **0.04**，表示整个线框来源模型最长边的 4%。仍密可试 **0.06–0.08**，会省略更多零件；设为 **0** 保留全部零件。按最大尺寸判断，细长支架不会仅因为截面很细就被过滤。
- **近邻线合并比例 / lineSpacingFraction**：合并靠得很近、方向近似平行且长度覆盖重叠的线，默认 **0.005**。仍密可试 **0.01**；设为 **0** 关闭。交叉后明显分开的边会保留。

这两个 Fraction 越大，图形越简略，细部和近距离结构边也可能省略。过滤仅作用于显示副本，可随时减小强度或切回旧模式恢复细节。分区与过滤不依赖相机，保留的正面、背面和内部线都参与绘制。

结构参数改变后才重新生成；Inspector 拖动会等待约 0.25 秒再处理，避免每一步都重建。颜色和线宽不触发网格重建。修改子物体缩放后可以点击“重新生成线框”更新尺寸门槛。

本项目“生命装置”模型实测：原始约 91,195 条边，推荐稀疏参数约 22,273 条边（减少约 76%）；0.06 约 19,186 条，0.08 约 17,497 条。代价是略去对应尺寸以下的独立细节；复杂内部结构仍会透视叠加。这是自动过滤，不会生成经过美术重拓扑的低模。模型在编辑器中一次重建约 1 秒，不能据此推断游戏帧率。

在现有 `Xray.cs` / `rayURP.shader` 上增加边线遮罩，保留原有 shader 名称与颜色、线宽、隐藏线、虚线、呼吸参数。`RetroWireframeMeshBuilder` 只生成临时显示网格，不修改原模型。

## 使用

1. 等 Unity 编译结束，选中挂了 **Xray** 的模型。
2. Inspector 顶部点击 **应用复古线框预设**。
3. 若原来的 Effect Material 不是 `X-Ray/Effects/XRay`，按钮会创建/复用同目录的 `M_Xray_Retro.mat` 并赋给组件，原材质不覆盖。
4. 预设使用细灰线、无填充，前后边全部显示；对应参考图里的建模软件线框视图。黑色背景由场景相机设置，不会自动改动你的相机。

## 参数

- **Edge Mode / Retro Quads**：按几何关系配对相邻三角形，尝试隐藏配对面的公共斜线，同时保留平面网格、球体经纬线、圆柱分段。匹配顺序固定，同一网格重复生成结果一致。
- **Edge Mode / All Triangles**：原来的完整三角线框，直接使用源网格。
- **Edge Mode / Feature Edges**：只保留边界、材质分界与明显折角；它会去掉许多曲面分段，不是参考图里的经纬网格风格。
- **Quad Max Angle**：允许配成四边面的两个三角形的最大面夹角，默认 10°。不改变线框分段数量；加大也不等于减面。
- **Feature Angle**：只影响 Feature Edges，角度越大，通常留下的折角越少。
- **Use Scene Occlusion**：开启后沿用原来的场景深度分类；关闭时所有边使用 Visible Lines 的风格，适合参考图的全透线框，不依赖相机深度纹理。
- **Wireframe Source Root**：可选的低模线框来源。来源物体要保持激活；它的原始表面由 Hide Original Model 隐藏，线框子物体仍会显示。源 Mesh 需要可读，无法读取时会给出警告并退回原三角线框。

改变结构参数会重新生成；改变颜色/线宽只更新 MaterialPropertyBlock。相同 Mesh 在一个组件内共用显示副本，关闭/销毁组件时释放。

## 如何达到参考图的稀疏程度

移除斜线不会把高模自动变成低模，也无法可靠恢复已经丢失的原始四边面拓扑。混乱的三角网格只能近似配对。

圆柱可以先用 **8–12 个周向分段**，球体先用 **8–12 条经线、4–6 层纬线**。复杂机械装置想要同样清爽，最好另做只保留箱体、罐体、门框和主要支架的低模版本，作为 Wireframe Source Root。平面分段网格在 Retro Quads 模式中会保留。

Use Scene Occlusion 开启时，仍使用原 shader 的场景深度逻辑。隐藏原模型后没有自身深度表面，不能据此精确区分自身正背面；复古预设关闭这一分类并显示全部线条，匹配参考图的表现。

## 验证

`Tests/RetroWireframe/RunValidation.ps1 -UnityPath <Unity.exe绝对路径>` 在 `.utmp/RetroWireframeValidation` 创建独立验证项目，不改动当前场景。它检验矩形、平面分段、UV 接缝、材质边界、四边面、立方体折角、显示遮罩、重复生成和释放，并实际渲染 URP shader。

输出位于 `Logs/RetroWireframeValidation.txt`、`Logs/RetroWireframe-Before.png`、`Logs/RetroWireframe-After.png`。样例的重建耗时只代表这些低模样例的 Editor CPU 生成开销，不代表实际机械装置的游戏帧率。原 shader 仍依赖 geometry shader，本次没有扩大它的图形 API 支持范围。
